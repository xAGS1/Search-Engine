# Inverted Index with Ranking System (BST & LinkedList Implementation)
This project implements an inverted index and ranking system for document processing. It allows you to search for keywords across a collection of documents and ranks the results based on the frequency of words in each document. It supports both a Binary Search Tree (BST) and Linked List for storing and retrieving word frequencies.

**Key features of the project:**
* Inverted Index: Maps words to documents and stores their frequency of occurrence.
* Ranking System: Ranks documents based on the frequency of the search terms.
* Supports Boolean Queries: Allows querying with operators like AND and OR.
* Unified Data Structure Support: Easily switch between BST and LinkedList for the index and search operations.
